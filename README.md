## 🌟 About

**TicTacToe** is an Android app project for the classic two-player, three-in-a-row game. The Android project is located in the [`android/`](android/) directory. The repository also contains a `license.txt`; read it before copying or redistributing the project.

> **Project note:** The root `readme.txt` is an old WebIntoApp export, not the app's development guide. This README focuses on the Android project and avoids repeating the app key or account links included in that legacy file.

## ✨ Game at a glance

- ❌⭕ Classic TicTacToe gameplay
- 📱 Android application project
- 🧰 Open and build using Android Studio and the project’s Gradle configuration

The exact game features, Android minimum version, and build variants are defined by the source and Gradle files under `android/`.

## 🧰 Requirements

- Android Studio (a current version compatible with the project's Gradle files)
- Android SDK/build tools required by the project
- An Android emulator or device for running the app

Check the Gradle files in `android/` for the precise Gradle, Android Gradle Plugin, and SDK versions.

## 🚀 Open and run

Clone the repository:

```bash
git clone https://github.com/Rawkesh2k/TicTacToeRepo.git
cd TicTacToeRepo
```

Then:

1. Open the `android/` directory in Android Studio.
2. Allow Gradle sync to complete and install any requested Android SDK components.
3. Select an emulator or connected Android device.
4. Run the app from Android Studio.

To build a release APK or app bundle, use the project's configured Gradle tasks or Android Studio's **Build > Generate Signed Bundle / APK** workflow. Exact task names depend on the Android project configuration.
